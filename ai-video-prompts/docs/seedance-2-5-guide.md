# Seedance 2.5 提示词指南（AI 漫剧向）

> Seedance 2.5 于 2026 年 8 月首发接入即梦 AI，是当前 AI 漫剧生产的主力模型之一。本指南聚焦「漫剧」场景，通用技巧可参考 `model-guide.md`。

## 一、能力速览（写提示词前要知道的事）

| 能力 | 说明 | 对漫剧的意义 |
|---|---|---|
| 原生 30s 音视频 | 单次生成最长 30 秒，含原生音频 | 一集竖屏漫剧可切成 2–4 段生成 |
| 超长模式 | 即梦内可串成约 3 分钟多镜头片段 | 连续剧情不用逐镜硬拼 |
| 多镜头叙事 | 单条提示词生成有逻辑关联的多个镜头，自动保持角色与风格一致 | 适合「正反打 / 情绪递进」段落 |
| 多模态参考 | 最多 30 张图、10 段视频、10 段音频 | 角色三视图、场景参考、BGM 都能喂 |
| 参考类型 | 角色 / 风格 / 运动 / 白模参考 | 锁定画风、动作、镜头运动 |
| 时间戳控制 | 可指定某时间段的动作、台词、角色 | 精修某 5 秒，不用整段重生成 |
| 智能编辑 / 多帧编辑 | 增删改局部画面 | 修穿帮、换表情、补镜头 |
| 原生音频 | 对白、环境音、BGM 多轨并行 | 漫剧可直接出声，减少后期 |
| 限制 | 真人主体参考需本人验证/授权；复杂多主体交互与极端运动仍可能失败 | 二次元漫剧不受真人限制；打斗戏建议拆镜 |

> 以上能力以即梦 / 火山方舟官方文档为准，版本更新较快。

## 二、漫剧提示词结构

```
[画风] + [镜头/景别] + [角色外观锚点] + [动作与表情] + [运镜]
+ [场景与光线] + [台词/音效] + [画质] + [负面约束]
```

示例（单镜头）：

> 2D 国漫赛璐璐画风，近景，黑长直红瞳少女穿着藏青色水手服，站在天台边缘，风吹动裙摆和发丝，她缓缓回头，眼神从疑惑转为震惊，镜头缓慢推近，黄昏逆光，暖橙色天空，电影级光影，口型与台词「你怎么会在这里」同步，4K，人物面部稳定不换脸。

示例（多镜头，带时间戳）：

> 2D 国漫赛璐璐画风，同一名黑长直红瞳少女与穿白衬衫的少年。
> 0–3s：雨夜街道远景，两人隔街相望，镜头缓慢横移；
> 3–8s：少女近景，雨水顺着发梢滴落，她咬唇、眼眶泛红；
> 8–12s：少年特写，伸手又收回，欲言又止。
> 整体冷蓝色调、体积光、雨丝清晰，人物面部稳定不换脸，4K。

## 三、漫剧专用技巧

### 1. 画风词放最前
漫剧画风差异大，先用一个短句定调：
`2D 国漫 / 日式赛璐璐 / 韩漫厚涂 / 动态漫 / Q 版泡面番 / 水墨国风`

### 2. 角色锚点要「固定短语」
同一角色的发型、瞳色、服装、配饰在每条提示词里**重复相同的短语**，例如：
> 黑长直、红色瞳孔、左耳银色耳钉、藏青色水手服

不要每次换说法（「黑发」/「墨色长发」/「乌黑秀发」会被模型当成不同特征）。

### 3. 表情要拆成肌肉动作
| 弱 | 强 |
|---|---|
| 她很难过 | 眼眶泛红、嘴唇轻颤、泪珠在睫毛上停留 |
| 他很生气 | 眉头紧锁、下颌绷紧、瞳孔收缩 |
| 她惊讶 | 微微张嘴、眼睛睁大、身体后仰半步 |

### 4. 台词与口型
- 台词用引号写进提示词：`口型与台词「……」同步`；
- 长台词拆短句，每句对应一个镜头；
- 若模型口型仍不准，用后期对口型工具补，提示词只保留情绪描述。

### 5. 分镜用时间戳
Seedance 2.5 支持时间控制，多镜头提示词写成：
`0–5s：……；5–12s：……；12–18s：……`
每段只放一个核心动作，段落之间用「切至 / 镜头转向」。

### 6. 参考图优先级
漫剧要用**图生视频**：先用 Seedream 生成角色三视图和首帧，再让 Seedance 参考首帧生成动态。参考图顺序：角色图 → 场景图 → 风格图。

### 7. 音频描述
不写「配一段好听的音乐」，写具体：
`环境音：雨声渐强；BGM：钢琴单音、缓慢、悬疑；台词：……`

### 8. 负面约束
漫剧常见负面：
```
换脸，五官漂移，多余人物，手指变形，文字乱码，画面抖动，风格突变，3D 渲染感，背景穿帮
```

## 四、故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 角色换脸 / 漂移 | 外观锚点不一致或缺参考图 | 固定短语 + 首帧图生视频 |
| 表情呆板 | 只写情绪词，没写肌肉动作 | 拆成「眉毛 / 眼睛 / 嘴 / 身体」 |
| 口型对不上 | 台词太长或模型音频错位 | 拆短句、每镜一句，或后期补 |
| 动作崩坏 | 一个镜头动作太多、多人交互 | 拆镜、降低动作幅度 |
| 风格乱变 | 画风词没前置或被冲淡 | 画风放句首，加参考风格图 |
| 画面抖动 / 闪烁 | 运镜过大或时长过长 | 缩短单镜时长、减小运镜幅度 |
