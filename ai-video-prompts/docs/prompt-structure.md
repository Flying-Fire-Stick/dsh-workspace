# 提示词结构：公式与拆解

## 一、万能公式

```
主体 + 外观 + 动作 + 环境 + 镜头运动 + 光线 + 风格/色调 + 画质 + 节奏 + 负面提示
```

| 模块 | 作用 | 示例 |
|---|---|---|
| 主体 | 画面核心是谁 / 是什么 | 一位年轻女性、一只橘猫、一瓶香水 |
| 外观 | 材质、服装、特征 | 黑色风衣、金属表壳、布满皱纹的手 |
| 动作 | **一个**核心动作 | 缓慢抬眼、匀速旋转、跃起 |
| 环境 | 场景、天气、氛围 | 雨夜街头、晨雾湖面、空旷仓库 |
| 镜头运动 | 机位、焦段、运动方式 | 低角度跟拍、35mm、缓慢推近 |
| 光线 | 光位与色温 | 侧逆光、黄金时刻、柔光箱 |
| 风格/色调 | 视觉风格与调色 | 电影感、吉卜力手绘、青橙色调 |
| 画质 | 分辨率与质感 | 4K、胶片颗粒、浅景深 |
| 节奏 | 速度、慢动作、延时 | 0.5x 慢动作、延时摄影 |
| 负面提示 | 明确要避免的东西 | 模糊、变形、水印 |

## 二、写作顺序建议

推荐按「从大到小」排列：先主体与环境，再动作，最后镜头、光线、风格。

- 先写「谁、在哪、在做什么」，让模型抓住语义主干；
- 镜头与光线放在中后段，避免稀释主体描述；
- 画质与风格放最后作为全局修饰；
- 负面提示单独一行或单独字段（取决于模型）。

## 三、中英文选择

| 场景 | 建议 |
|---|---|
| Sora / Veo | 英文自然语言长句，像写分镜剧本：`A woman sits by a window... the camera slowly pushes in...` |
| Runway / Pika | 英文短句 + 关键词，控制长度 |
| 可灵 / 即梦 / 万相 | 中文完整句，可加结构化标签 |
| 老一代模型（SVD 等） | 关键词堆叠，少用长句 |

实操建议：**同一提示词备中英两版**，中英混写容易产生语义冲突。

## 四、时长与节奏

- 多数模型单次生成 4–10 秒，**4–8 秒最稳**；
- 一个镜头只做一个动作，动作量要匹配时长；
- 慢动作明确写 `slow motion` / `0.5x`；
- 延时效果写「快速流动的云」「星空延时」，必要时后期加速；
- 超过 10 秒优先用模型原生延长，或分段生成后剪辑。

## 五、常见错误

1. **一个镜头塞多个动作**：「走过来、坐下、喝水、看表」——模型会跳帧或丢动作；
2. **镜头指令矛盾**：「固定机位」+「跟拍」；
3. **形容词堆砌**：「绝美、震撼、史诗、顶级」没有信息量；
4. **主体不明确**：只写场景不写谁在做什么；
5. **中英混写**：主语与镜头指令语言不同，理解容易打架；
6. **时长不匹配**：2 秒要写完整 10 秒的叙事。

## 六、通用负面提示词

中文：

```
模糊，变形，多余的手指，文字，水印，logo，低分辨率，过曝，欠曝，闪烁，跳帧，塑料感，蜡像感，肢体扭曲
```

英文：

```
blurry, deformed, extra fingers, text, watermark, logo, low resolution, overexposed, underexposed, flickering, frame skipping, plastic look, waxy skin, distorted limbs
```

## 七、占位符约定

本库统一用以下占位符，替换时保留句子结构：

| 占位符 | 含义 |
|---|---|
| `{主体}` | 人物 / 动物 / 物体 |
| `{场景}` | 地点、天气、时间 |
| `{动作}` | 一个核心动作 |
| `{镜头}` | 运镜与焦段 |
| `{光线}` | 光位与色温 |
| `{风格}` | 视觉风格 / 参考类型 |

示例：

```
{主体} 站在 {场景} 中 {动作}，{镜头}，{光线}，{风格}，4K。
```
