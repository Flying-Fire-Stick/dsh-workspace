# 运镜词典（中英对照）

写视频提示词时，**机位 + 运动 + 方向 + 速度**要一起说清楚，例如：
`低角度跟拍，镜头缓慢向右横移` / `low-angle tracking shot, camera slowly trucks right`。

## 一、基础运镜

| 中文 | English | 效果 | 提示 |
|---|---|---|---|
| 推镜头 | dolly in / push in | 靠近主体，增强情绪 | 与 zoom 不同：推是物理靠近，背景透视会变 |
| 拉镜头 | dolly out / pull back | 远离主体，揭示环境 | 常用于结尾 |
| 摇镜头 | pan left / pan right | 机位不动、镜头水平摇 | 适合展示全景 |
| 俯仰 | tilt up / tilt down | 机位不动、镜头上下摇 | 仰拍显高大、俯拍显渺小 |
| 移镜头 | truck / lateral move | 机位平行移动 | 常配「缓慢横向」 |
| 跟拍 | follow / tracking shot | 镜头跟着主体走 | 写明「从背后 / 侧面」 |
| 升降 | crane up / crane down | 垂直升降 | 航拍感强 |
| 环绕 | orbit / arc shot | 围绕主体转圈 | 写明角度，如 180° / 360° |
| 变焦 | zoom in / zoom out | 焦距变化 | 写清「光学变焦」避免混淆 |
| 希区柯克变焦 | dolly zoom / vertigo effect | 推拉与变焦反向，产生眩晕 | 强视觉冲击，慎用 |
| 手持 | handheld | 轻微晃动，纪实感 | 别与「稳定」同写 |
| 斯坦尼康 | steadicam | 平滑跟随 | 适合长镜头 |
| 航拍 | aerial / drone shot | 高空视角 | 可加「俯视」「环绕」 |
| 穿越机 | FPV drone | 第一视角高速穿梭 | 速度感强，注意别写「缓慢」 |
| 转台 | turntable | 产品匀速自转 | 产品广告常用 |
| 微距 | macro | 极近距离细节 | 配合浅景深 |
| 广角 | wide angle | 视野开阔、边缘畸变 | 适合风景、空间 |
| 长焦 | telephoto | 空间压缩、突出主体 | 适合人像、远景 |
| 低角度 | low angle | 仰视，增强压迫 / 英雄感 | 适合人像、建筑 |
| 高角度 | high angle | 俯视，显弱小 / 全局 | 适合叙事 |
| 俯拍 | top-down / bird's-eye | 正上方垂直向下 | 产品、美食常用 |

## 二、组合建议

- 一个镜头**最多一个主运动**，附加一个次要修饰（如「缓慢推近 + 轻微手持」）；
- 运动方向写清楚：left / right / up / down / forward / backward；
- 速度用 `slow` / `fast` / `gentle` / `rapid` 明确；
- 360° 环绕、穿越机等大运动，尽量配短时长（4–6 秒）和宽阔场景。

## 三、常用英文句式

```
slow dolly-in on the subject
low-angle tracking shot following the character from behind
camera orbits the subject 180 degrees
slow crane up revealing the landscape
handheld camera with subtle shake
static shot, no camera movement
```

> 需要「完全静止」时，明确写 `static shot / locked-off camera`，否则模型常会自动加运动。
