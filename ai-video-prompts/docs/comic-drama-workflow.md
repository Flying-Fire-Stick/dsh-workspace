# AI 漫剧制作流程（Seedance 2.5 版）

AI 漫剧 = 用 AI 生成画面与声音的**竖屏动漫短剧**（单集 1–3 分钟，9:16）。工业化关键不在「生成」，而在**角色一致性**与**分镜节奏**。

## 一、整体流程

```
IP 设定 → 剧本与分镜 → 角色资产 → 分镜生成 → 配音/音效 → 剪辑字幕 → 发布复盘
```

| 阶段 | 产出 | 工具/方法 |
|---|---|---|
| IP 设定 | 角色小传、世界观、画风基调 | 文档 + 参考图 |
| 剧本分镜 | 分镜表（镜号/景别/运镜/台词） | 模板见 `templates/shot-list-template.md` |
| 角色资产 | 三视图、表情包、服装变体 | Seedream / 即梦生图 |
| 分镜生成 | 每镜 4–30s 视频 | Seedance 2.5（图生视频优先） |
| 配音音效 | 对白、BGM、环境音 | 原生音频或后期 TTS |
| 剪辑字幕 | 成片、封面 | 剪映 / PR |
| 发布复盘 | 数据反馈 | 平台后台 |

## 二、角色一致性（漫剧的生死线）

1. **固定外观短语**：给每个角色写一段 20 字内、每次原样复制的描述；
2. **三视图 + 表情包**：正面 / 侧面 / 背面 + 喜怒哀乐，作为参考图；
3. **首帧锁定**：每个镜头先出静态图（首帧），再用图生视频，避免模型自由发挥；
4. **同一场景批量生成**：相邻镜头放在同一条多镜头提示词里，减少风格漂移；
5. **审片检查表**：脸型、瞳色、发型、服装、配饰、画风六项逐一对照。

## 三、分镜节奏（竖屏漫剧）

- **黄金 3 秒**：第一镜必须有冲突 / 悬念 / 反常画面；
- **单镜 3–8 秒**：超过 8 秒观众注意力下降，也更容易崩；
- **每 15–20 秒一个小钩子**：反转、秘密、情绪爆发；
- **对白驱动**：漫剧靠台词推进，画面服务于台词情绪；
- **结尾留钩**：最后一镜停在悬念或反转上。

## 四、生成策略

1. **先图后视频**：静态首帧 → 图生视频；纯文生视频只用于空镜、氛围镜；
2. **多镜头成组**：同一场景的 2–4 个镜头放进一条提示词，用时间戳分隔；
3. **单镜单动作**：打斗、多人互动拆成多个短镜，再剪辑拼接；
4. **音量控制**：原生音频好用，但 BGM 建议后期统一混音，避免每段响度不一；
5. **失败重试原则**：连续 2 次失败就改提示词或拆镜，不要硬抽卡。

## 五、成本与产能参考

| 项目 | 参考值 |
|---|---|
| 单集时长 | 60–180 秒 |
| 镜头数 | 15–40 个 |
| 单镜生成次数 | 平均 1.5–3 次 |
| 角色参考图 | 3–5 张 / 角色 |
| 制作周期（个人） | 1–3 天 / 集 |

## 六、常见问题

- **角色漂移**：参考图不足、外观短语不固定 → 补三视图、固定短语；
- **画面像 PPT**：运镜太保守 → 每镜至少一个轻微运镜；
- **口型不对**：长台词硬塞 → 拆短句，每镜一句；
- **节奏拖**：一个镜头讲太满 → 按「冲突-反应-推进」三拍拆镜；
- **侵权风险**：不要直接复刻受版权保护的知名角色形象，做原创或明确授权的 IP。
