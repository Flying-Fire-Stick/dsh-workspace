# 漫剧分镜提示词模板 v2（AI 友好 · 优化版）

> 基于你提供的《我的系统穿女仆装…》锁定模板版优化而来，保留其「段/切 + 参考帧 + 末态 + 声音 + 锁定」的骨架，重点补齐 **AI 视频模型真正吃得进的控制字段**：动作起止、运镜速度幅度、转场、首尾帧、音频分轨、负面提示词、一致性校验。
> 适用：Seedance 2.5 / 可灵 / Veo / Runway 等；默认 9:16、24fps、单切 2–8 秒。

---

## 一、原模板的问题诊断

| 问题 | 原模板表现 | 后果 | v2 方案 |
|---|---|---|---|
| 动作只有「结果」没有「起止」 | 「他抬手」「她转身」 | 模型自由发挥，容易多动作/穿模 | 每切写 `动作起→止` + 运动幅度 |
| 运镜只有名称 | 「缓推」「跟拍」 | 速度/幅度不可控，切与切之间节奏乱 | `运镜：类型/速度/幅度/方向` 四要素 |
| 切间无转场说明 | 只标时间码 | 多镜头生成时切点生硬或误切 | 每切末尾标 `转场：硬切/叠化/甩镜` |
| 参考帧只有时间对齐 | 「图1 对齐 0.00s」 | 不知道参考图是首帧、尾帧还是角色图 | `R1 首帧 / R2 角色参考 / R3 风格参考` |
| 负面词混在【锁定】里 | 一段长句 | 模型难分层，负面权重不稳定 | 独立 `【负面】` 字段，按场景定制 |
| 风格/光影每段重复长句 | 段段复写 | token 浪费、容易前后不一致 | 全局 `STYLE-A/B` 锚点，段内只写差异 |
| 音频只有一行 | `<滴水声、灯管…>` | 对白/BGM/音效混在一起，后期难拆 | 对白（口型）/环境/BGM/音效 四轨 |
| 无质检环节 | 无 | 生成后靠肉眼逐条找问题 | `【质检】` 五项勾选 + 重试策略 |
| 无模型参数 | 只有 T2V | 与 Seedance 2.5 能力脱节 | `【参数】` 写明 T2V/I2V、时长、参考图上限 |

## 五、AI 友好写法约定（写模板时遵守）

1. **一切可量化**：时间用「起–止–时长」三列；运镜速度只用「慢/中/快」；幅度只用「小/中/大」。
2. **一切有起止**：每切只写一个核心动作，写成 `起→止`，避免「然后」「接着」。
3. **台词只出现在开口镜头**：画外音标 `唇形闭合`，对话镜头标 `口型同步`，长台词拆切。
4. **转场显式化**：硬切默认；叠化/甩镜只在需要时写，且下一段首帧要与上一段末态衔接。
5. **参考图分层**：`R1 首帧` 锁构图；`R2 角色` 锁脸；`R3 风格` 锁画风；`R4 尾帧` 锁末态。
6. **负面词分层**：基础负面 + 本段专属负面，独立字段，不要混进画面描述。
7. **锚点编号化**：角色/道具/空间/风格全部编号，段内只写编号，减少长句漂移。
8. **风格与光影只写差异**：公共部分引用 STYLE/S 锚点，段内只写本段变化。
9. **末态可续接**：末态必须写「姿态终点 + 视线方向 + 机位光源不变」，保证下一段能接。
10. **单切时长 2–8 秒**：超过 8 秒拆切；多镜头段落用 `0.00s–3.50s` 时间戳写法一次生成。

## 六、Seedance 2.5 参数建议

| 字段 | 建议 |
|---|---|
| 画幅 / 帧率 | 9:16 / 24fps（漫剧）；仿真人可用 30fps |
| 单切时长 | 2–5s 最稳；情绪特写 3–4s |
| 生成方式 | 角色/构图优先 **I2V**（首帧 + 角色参考）；氛围空镜可 T2V |
| 参考图 | 每段 ≤4 张：首帧 1 + 角色 1–2 + 风格 1 |
| 多镜头 | 同场景 3–5 切用时间戳一次生成，切点对齐【参考】 |
| 音频 | 台词写进提示词并标「口型同步」；BGM/环境音分轨后期混音 |
| 时长上限 | 单段 30s；超长剧情拆段，段间用【末态】衔接 |

## 七、质检与重试策略

**生成后逐项检查**：脸是否漂移 → 服装是否一致 → 道具结构是否崩 → 轴线是否越 → 光源方向是否变 → 有无文字/水印 → 动作是否穿模。

**重试规则**：

- 同一段连续 2 次失败：**拆切**（把复杂动作拆成两个短切），不要继续抽卡；
- 角色脸不稳：换 `R2` 角色参考图，优先用正面清晰定妆照；
- 切点生硬：改用多镜头时间戳一次生成，或在剪辑里加 2–3 帧叠化；
- 画面糊：降低动作幅度/运镜速度，检查是否爆显存。
