# 光线、色彩与质感关键词

视频的「高级感」很大程度来自光线与调色。提示词里写清**光位 + 色温 + 质感**，比写「电影感」有效得多。

## 一、光线

| 中文 | English | 效果 |
|---|---|---|
| 自然光 | natural light | 真实、柔和 |
| 黄金时刻 | golden hour | 低角度暖阳，轮廓光强 |
| 蓝调时刻 | blue hour | 日落后冷蓝，安静氛围 |
| 柔光 | soft light | 阴影过渡柔和，适合人像 |
| 硬光 | hard light | 阴影锐利，戏剧冲突 |
| 侧光 | side light | 强调立体感 |
| 逆光 | backlight | 剪影、发丝光 |
| 侧逆光 | side-back light | 轮廓 + 立体，人像常用 |
| 轮廓光 | rim light | 勾边，分离主体与背景 |
| 体积光 | volumetric light | 光束可见，适合林间、舞台 |
| 伦勃朗光 | Rembrandt lighting | 经典人像布光 |
| 顶光 | top light | 压抑或神圣感 |
| 剪影 | silhouette | 只留轮廓 |
| 霓虹光 | neon light | 赛博、夜街 |
| 实用光 | practical light | 画面内的灯（台灯、招牌） |

## 二、色彩

| 中文 | English | 感觉 |
|---|---|---|
| 暖色调 | warm tones | 温馨、怀旧 |
| 冷色调 | cool tones | 理性、疏离 |
| 青橙色调 | teal and orange | 电影感、好莱坞常用 |
| 低饱和 | desaturated | 克制、纪实 |
| 高饱和 | vivid / saturated | 张扬、商业 |
| 单色 | monochrome | 高级、极简 |
| 赛博配色 | cyan and magenta | 霓虹、未来 |
| 粉彩色 | pastel | 清新、少女感 |
| 复古胶片 | vintage film | 颗粒、偏色 |

## 三、质感与镜头语言

| 中文 | English | 效果 |
|---|---|---|
| 浅景深 | shallow depth of field | 背景虚化、突出主体 |
| 胶片颗粒 | film grain | 复古、真实 |
| 柔焦 | soft focus | 梦幻、柔美 |
| 光晕 | bloom / glow | 高光溢出 |
| 变形宽银幕 | anamorphic | 横向眩光、电影感 |
| 广角畸变 | wide-angle distortion | 空间张力 |
| 微距细节 | macro detail | 材质纹理 |
| HDR | high dynamic range | 明暗层次丰富 |
| 真实感 / 照片级 | photorealistic | 反 AI 塑料感 |

## 四、常用组合

- 人像：`侧逆光 + 黄金时刻 + 浅景深 + 35mm 胶片`
- 产品：`轮廓光 + 黑色背景 + 微距 + HDR`
- 夜景：`霓虹 + 湿地面反射 + 青橙调色`
- 自然：`晨雾 + 体积光 + 冷蓝调 + 广角`
- 复古：`暖黄 + 胶片颗粒 + 柔焦`

> 提示：光线写太多会互相打架，一个画面**最多两种主光源**。
